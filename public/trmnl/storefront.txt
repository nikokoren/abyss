Use with the existing polling recipe
1. Temporarily change the polling URL to:
   https://raw.githubusercontent.com/nikokoren/abyss/main/trmnl/storefront.json
2. Keep the GET method, Python transform and existing layouts.
3. Clear Underwater cameras, or select Oregon Offshore: seafloor.
   Selecting another camera will produce an empty view because this payload
   deliberately contains just one camera.
4. Leave Show QR code off for an uncluttered storefront capture.
5. Refresh the plugin data, then let TRMNL render the storefront image using
   the full-screen layout. The photograph stays fixed across refreshes.

Use with static/sample JSON input
Paste the entire contents of storefront.json into the recipe's static/sample
JSON data field. It includes both the single-source catalog expected by the
Python transform and current_camera/abyss_ready for direct markup previews.
No markup or transform replacement is necessary.

After capturing the storefront image
Restore the production polling URL before submitting the recipe:
https://nikokoren.github.io/abyss/catalog.json
Restore your preferred camera selections. A full recipe re-import would also
restore its production URL; avoid doing that until after the capture.
