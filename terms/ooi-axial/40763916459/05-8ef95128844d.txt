Platforms and Nodes List
This page provides a comprehensive listing of deployed infrastructure (i.e., platforms and nodes) across OOI arrays. Selecting the Array name provides a detailed description of the array. Selecting a Platform Name, ID, or DOI opens a detailed landing page mapped to the corresponding Digital Object Identifier (DOI). The landing page provides citation guidance, data access resources, descriptions, and a table of associated instruments. Each platform and instrument link directs users to their location within the OOI Data Explorer or to other resources on our data access page for further data exploration and download. This inventory enables cross-referencing of infrastructure and datasets to support time-series analyses, model-data comparisons, process studies, and integrated investigations across OOI’s Coastal, Global, and Cabled arrays.
Additional Access to OOI-Related Data
These pathways provide access to publications and curated OOI-based datasets, enabling cross-referencing for time-series, model–data, process, and integrated studies across OOI arrays.

Platforms
Platform: An infrastructure setup that supports integrated scientific instruments. It can be fixed (e.g., a surface mooring) or mobile (e.g., a profiler mooring or glider). Platforms often contain multiple nodes for instrument attachment and data transmission to shore.
